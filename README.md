# BiGER
> Bayesian Rank Aggregation in Genomics with Extended Ranking Schemes

This package implements a Bayesian rank aggregation algorithm for meta-analysis. In bioinformatics, a common form of data is presented as gene lists, and it is of great interest to study gene lists generated by multiple studies in the same discipline. With the rise of omics studies as well as an information overflow in the scientific literature and popular discourse, finding a consensus with interpretable results is of utmost important. This is where we come to rescue. 

Named **B**ayesian Rank Aggregation **i**n **G**enomics with **E**xtended **R**anking Schemes (BiGER), BiGER can handle a variety settings, including top-ranked studies, top-unranked studies, and a generalization with mixed studies. Turbocharged with variational inference (VI), BiGER achieves blazingly fast speed that rivals some of the most efficient methods in the field. Given BiGER's Bayesian framework, we also provide estimates for each input study's variance, giving users a practical guideline for study selection as well as guided-investigation.

## Installation

Currently, this package is hosted on GitHub only. You can install this package by running the following command in R:

```R
devtools::install_github("kevin931/BiGER")
```

The `BiGER` package along with its dependencies should install seamlessly in trivial time (within minutes). The package should work with all major platforms (**e.g.** Windows, MacOS, and Linux) on which R works. The package was developed and tested with Windows 11 with R 4.4.0.

This package depends heavily on `Rcpp` for optimization of code because we all want to save some precious time so that we can go outside rather than sitting by our computer all day. Therefore, we require the following dependencies:

- Rcpp (>=1.0.9)
- RcppTN (>=0.2)

This requirement is not very stringent.

## Documentation

We have included an example dataset that you may use to test out the BiGER package. To get started, we assume that your working directory is in the root of this BiGER directory. You may use the following examples.

### Example Dataset

First, let's load the BiGER library, after you have installed the package:

```r
library(BiGER)
```

You will need to read in the data:

```r
r <- read.csv("./example/r.csv")
metadata <- read.csv("./example/r.csv")

r <- as.matrix(r)
```

Then, to run BiGER with VI, simply run

```r
BiGER(r = r, n_r = metadata$ranked, n_u = metadata$unranked)
```

Or, if you wish to run `gBiGER` with Gibbs sampling, run

```r
gBiGER(r = r, n_r = metadata$ranked, n_u = metadata$unranked)
```

In these example, all defaults are used. BiGER should finish within seconds, and gBiGER should also take well under a minute to run on a standard desktop computer.

### BiGER and gBiGER Outputs

For gBiGER, we output a list with the following:

- Estimated global gene importance (mu)
- Estimated study specific variance (sigma^2)
- Estimated study specific precision (1/sigma^2)
- Delta values for convergence detection

For gBiGER, we output a list with the following:

- Posterior mean for mu
- Posterior median for sigma^2
- Full chains for mu and sigma^2 (optional)

### Genelist Inputs

Notice that our example includes a direct matrix input, which has the advantage of distinguishing between bottom ties and missing genes. However, it is also convenient to use a simple genelist for input.

To do so, you can simply preprocess your genelist (in the form of R list with each vector as a study) into a rank matrix:

```r
r <- preprocess_genelist(genelist = genelist, n_r = metadata$ranked, n_u = metadata$unranked)
```

The `n_r` and `n_u` parameters correspond to the number of top-ranked and top-unranked genes in a given genelist. We assume that top-ranked genes are ordered in the given order and come before top-unranked genes.

For additional customization options, see its corresponding documentation.
